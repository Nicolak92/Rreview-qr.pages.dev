How to make a CSS gradient

  1. Choose linear, radial or conic.
  2. Change the colors and their positions. Add up to six colors.
  3. Set the angle for linear and conic gradients.
  4. Copy the CSS and paste it into your stylesheet, or download a PNG.

Gradient types

  • Linear: colors blend along a straight line.
  • Radial: colors spread out from the center.
  • Conic: colors rotate around the center, like a color wheel.

Tips

Use colors that are close on the color wheel for a smooth, calm look. Check that text on top of the gradient stays easy to read.

Is the CSS gradient generator free?

Yes. Make as many gradients as you like, with no sign-up.

Do I need a fallback color?

The code includes a solid fallback color line for very old browsers, followed by the gradient.

How do I use the code?

Paste it inside any CSS rule, for example in .hero or body. You can also put the value in a style attribute.

Can I download the gradient as an image?

Yes. Press Download PNG for a 1600 by 900 image. Conic gradients need a recent browser.

Does it work in all browsers?

Linear and radial gradients work everywhere. Conic gradients work in current versions of all major browsers.
