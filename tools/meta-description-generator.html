Your title and description

Google may show a different title or description depending on the search. The preview is a guide, not a promise.

How to write a meta description

  1. Enter the main keyword, what the page offers, and its main benefit.
  2. Press Suggest titles and descriptions. Click Use beside the ones you like.
  3. Edit the text. Watch the length meters and the search preview.
  4. Copy the HTML and paste it into the head of your page.

Length guide

  • Title: about 50 to 60 characters, or roughly 580 pixels wide.
  • Description: about 120 to 155 characters.
  • Put the important words first, because the end may be cut off.

What makes a good meta description?

It should describe the page honestly, include the main keyword once, and give a reason to click. Every page should have its own, not a copy of another page.

Is the meta description generator free?

Yes. Use it as often as you like, with no sign-up.

Does it use AI?

No. It uses proven writing patterns with your words, so nothing is sent anywhere.

Does a meta description help rankings?

It is not a direct ranking factor, but a clear description can get more people to click your result.

How long should it be?

Aim for 120 to 155 characters. Longer ones are often cut off in search results.

Will Google always use mine?

No. Google sometimes writes its own snippet from the page. A good description is used more often.
